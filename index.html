📦 What agentcp Is

agentcp is a small desktop application for Mac that keeps your AI coding helpers in one place. If you have ever worked with Claude Code and Codex, you already know the annoyance: one tool keeps its notes in a file here, the other keeps its settings in a file there, and remembering which is which becomes a chore.

agentcp puts both of them side by side. You open one window, see what is configured, and adjust things with a few clicks. There is nothing to install in a terminal, nothing to type on a command line, and nothing to pay. It is free and the source code is open for anyone to read.

The app is built for people who use AI assistants to help with writing, coding, research, and everyday computer tasks — but who would rather not babysit a pile of configuration files.

✨ What You Can Do With It

  • See both assistants at once. Claude Code and Codex live in the same window, so you always know which one you are looking at.
  • Manage your agents.md file. Keep the shared instruction file for your AI agents tidy and easy to update, without hunting through folders.
  • Manage your claude.md file. Edit the guidance that shapes how Claude Code behaves, in a plain, readable view.
  • Keep MCP connections organized. Model Context Protocol settings are grouped together, so connecting new tools does not turn into a scavenger hunt.
  • Switch contexts quickly. Move between projects or setups without closing and reopening a dozen things.
  • Stay local. Everything lives on your own computer. There is no sign-up form and no cloud account to manage.

🚀 Getting Started

You do not need any technical background to get up and running. The whole process is a download, an open, and a short first-time setup. Follow these steps in order:

  1. Open the download page. Use the link in the next section. It takes you to the official releases page where the application is published.
  2. Download the application. Find the most recent release at the top of the page and download the application file attached to it.
  3. Wait for the download to finish. The file usually lands in your Downloads folder. A progress indicator in your browser will tell you when it is done.
  4. Open the downloaded file. Double-click it to launch agentcp. If your computer asks whether you are sure you want to open it, confirm that you do.
  5. Approve the first-launch prompt. Your system may ask for permission to open an app from the internet. Allow it once, and you will not be asked again.
  6. Look around. When the main window appears, you are finished. Nothing else needs to be configured before you can explore.

🖥️ Your First Five Minutes

When agentcp opens for the first time, the window may look plain — that is normal. It starts empty because it has not found any existing setup yet. Here is a comfortable way to explore:

  1. Read the main panel left to right. The left side lists what agentcp knows about, and the right side shows details for whatever you select.
  2. Click each item once. Clicking never changes anything; it only shows you information. Feel free to look around.
  3. Find the Claude Code area. This is where the claude.md guidance lives. You can read it without editing.
  4. Find the Codex area. This holds the parallel setup for Codex, alongside the shared agents.md instructions.
  5. Make one small change. Edit a single line of text and save it. That is the whole learning curve — everything else works the same way.

🗂️ Keeping Things Organized

The real benefit of agentcp shows up after a week of use, when you have a few projects going at once. A few habits make that easier:

  • One project, one entry. Give each project a clear name so you can find it instantly instead of guessing.
  • Write instructions in plain language. The agents.md and claude.md files are read by AI assistants, so short, direct sentences work better than clever wording.
  • Keep shared rules in agents.md. Anything that should apply to every assistant belongs there, not duplicated in three places.
  • Group MCP connections by purpose. Name them after what they do — for example, the tool they connect to — rather than by date.

🔐 Privacy and Safety

agentcp runs on your computer and works with files that are already there. There is no sign-in screen, no subscription, and no profile to fill out. Because the project is open source, anyone can inspect how it behaves — a meaningful difference from closed tools that ask for trust without evidence.

As with any app you download, get it from the official releases page rather than a third-party mirror. That page is the only place where the current, unmodified build is published.

💡 Tips for a Smooth Experience

  • Keep the app updated. Check the releases page occasionally; newer versions fix rough edges and add support for changes in the assistants themselves.
  • Note where things live. If you edit a file outside agentcp, the app may show older content until it refreshes.
  • Do not delete files you do not recognize. Some files look unimportant but are read by Claude Code or Codex every time they start.
  • Back up before big edits. Copying a file to a second folder takes seconds and saves an afternoon of reconstruction.

🛠️ Troubleshooting

  • The download never starts. Reload the releases page and try again. If your browser blocks the file, look for a small warning icon in the address bar and allow the download.
  • The app will not open. Your system may be protecting you from unrecognized software the first time. Open the app once more and confirm the prompt that appears.
  • The window is empty. That usually means no existing setup was found where the app looked. Confirm the files you expect to see actually exist on the computer.
  • Changes do not stick. Make sure the file is not open in another program at the same time; two editors writing the same file will overwrite each other.
  • Something looks broken. Quit the app completely and reopen it. If the problem continues, check the release notes for the version you installed.
